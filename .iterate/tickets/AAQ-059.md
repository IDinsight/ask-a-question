**Target:** dsem Level 3 · **Skill:** dsem-ci-cd (github-actions-python.md)

## What's wrong now
- `tests.yaml:2-9` and `linting.yaml:2-8` trigger on push only and filter `**.py`; PRs changing only `uv.lock`, `pyproject.toml`, `alembic.ini` or the Dockerfile run no tests; fork PRs get no CI.
- No caching in `tests.yaml`; broken `export` at `tests.yaml:60-62` (and `109-111`) — missing trailing backslash so `ALIGN_SCORE_API` is never exported.
- `alembic-migrations.yaml:48` uses `ref: github.head_ref`, which fails for fork PRs.

## What needs to change
- `.github/workflows/backend-ci.yml`: `on: pull_request` + `push: main`, paths `core_backend/**`, root `pyproject.toml`, the workflow file.
- Jobs `lint` (ruff, black), `type-check` (mypy), `test` (alembic tests then unit tests with pgvector + Redis services) using `astral-sh/setup-uv` with `enable-cache: true` and `uv sync --frozen`.
- Fix the env export and fork-PR ref; retire `tests.yaml` and `linting.yaml`.

## Done when
- A PR changing only `core_backend/uv.lock` triggers lint, type-check and test; jobs show cache hits.
