## What's wrong now
- `users/routers.py` (1193 lines) holds validation helpers `check_create_or_add_user_call`, `check_update_user_call` etc. (`:835-1190`).
- `users/models.py` (1227 lines) mixes ORM, 8 commits, and an `assert`-based check (`:306`).
- `register-first-user` does 3 separate commits (workspace `workspaces/utils.py:92`, user `users/models.py:1030`, role) — orphans on failure.

## What needs to change
- Add `users/service.py` and `users/persistence.py`; create / add-existing / remove user each run in one transaction.
- `UserAlreadyExistsError` → `ConflictError`.

## Done when
- Injected failure after user insert leaves no user or workspace row.
- Service tests cover role rules and last-admin removal.
