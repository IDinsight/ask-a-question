## What's wrong now
- Protection is client-only: `src/components/ProtectedComponent.tsx:19-40` renders `null` until an effect runs, then `router.push('/login…')`. No `middleware.ts`.

## What needs to change
- Add `src/middleware.ts` (→ `proxy.ts` after Next 16) redirecting requests without a session cookie to `/login?sourcePage=…`.
- Matcher covers `/`, `/content`, `/dashboard`, `/urgency-rules`, `/integrations`, `/workspace-management`; excludes `/login`, `/reset-password`, `_next`, static assets.
- Keep `ProtectedComponent` only as UX fallback or remove it.

## Done when
- Unauthenticated `GET /content` → 307 to `/login` (Playwright).
- Matcher coverage documented.
