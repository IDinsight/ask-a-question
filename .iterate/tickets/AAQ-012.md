**Target:** dsem Level 3 · **Skill:** dsem-security

## What's wrong now
- `dashboard/plotting.py:63-67` builds `display_text` from raw end-user query text; CustomJS at `:373-381` concatenates it and the LLM `topic_title` into HTML and sets `div.text` (Bokeh `Div` renders HTML).
- admin_app embeds it via `embed.embed_item` (`admin_app/src/app/dashboard/.../Bokeh.tsx:57-61`), so a query like `<img src=x onerror=...>` would execute in an admin session (likely; not runtime-verified).
- bokeh 3.5.1 has an open advisory.

## What needs to change
- `html.escape` `text` and `topic_title` before building the `ColumnDataSource`, or build DOM nodes with `textContent` in the CustomJS.
- Upgrade bokeh.

## Done when
- Test feeds an HTML payload as a query and asserts the returned plot JSON contains only escaped entities.
- Manual check: the selection panel renders the text literally.
