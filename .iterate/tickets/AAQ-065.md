**Target:** dsem Level 3 · **Skill:** dsem-ci-cd (quality gate: no sensitive values logged)

## What's wrong now
- `echo '${{ steps.secrets.outputs.gcp-credential-json }}' > .gcp_credentials.json` (`deploy_gcp_core_backend.yaml:91`, `deploy_gcp_litellm_proxy.yaml:83`).
- `echo '${{ steps.compute-ssh.outputs.stdout }}'` in every deploy file (core:155-156, admin:120-121, caddy:111-112, litellm:115-116, redis:88-89) — interpolates untrusted output and logs remote output.
- Secrets passed as `-e KEY="..."` in the remote command (core:132-148), visible via `docker inspect` on the VM.

## What needs to change
- Pass values via `env:` and `printf '%s' "$VAR"`; drop/sanitise stdout echo steps.
- Write a mode-600 env file on the VM and use `--env-file`.

## Done when
- No `${{ steps.*.outputs.* }}` or `${{ secrets.* }}` inside `run:` bodies or remote `command:` strings; deploys still pass.
