**Target:** dsem Level 3 · **Skill:** dsem-security

## What's wrong now
- `/voice-search` and `/voice-search-chat` fetch any user-supplied URL (`question_answer/speech_components/utils.py:219-225`). Reviewer rated this High and recommended pulling it into L3 even though the skill lists broader SSRF hardening at L4.

## What needs to change
- Allowlist schemes (`https`) and hosts (configured storage bucket / Turn.io media hosts).
- Resolve and block private, loopback, link-local and cloud-metadata IPs (incl. redirects); cap download size and timeout.

## Done when
- Tests: `http://169.254.169.254/...`, `http://localhost`, a private IP and a non-allowlisted host are rejected with 400; an allowlisted URL still works.
