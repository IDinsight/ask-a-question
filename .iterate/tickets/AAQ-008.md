**Target:** dsem Level 3 · **Skill:** dsem-security (references/fastapi.md)

## What's wrong now
- Tokens carry mutable `username` / `workspace_name` / `user_role` with no `sub`, `iss`, `aud` (`auth/dependencies.py:212-224`).
- Default expiry is 7 days (`auth/config.py:5`); decode does not require `exp`.
- pyjwt 2.8.0 has open advisories (pip-audit).

## What needs to change
- Issue `sub=str(user_id)`, `workspace_id`, `iss`, `aud`; decode with `options={"require": ["exp", "iat", "sub"]}` and issuer/audience checks.
- Cut default expiry to ≤ 24h (refresh/renewal is L4).
- Keep role out of authZ decisions (it already comes from the DB).
- Upgrade PyJWT; update admin_app if it decodes claims.

## Done when
- Tests: expired, missing-`exp`, wrong-`aud`, `alg=none`, HS256 re-signed with another key, and missing-`sub` tokens all return 401.
