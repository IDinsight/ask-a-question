## What's wrong now
- `admin_app/package.json` scripts are only `dev`, `build`, `start`, `lint`, `test:ui` (interactive), `format`; no `typecheck`, `test`, `test:e2e`, `format:check`.
- No `.nvmrc` / `packageManager` / `engines`.
- Playwright runs against `pnpm run dev` with `html` reporter only (`playwright.config.ts`).

## What needs to change
- Scripts: `typecheck` (`tsc --noEmit`), `test` (`vitest run`), `test:e2e` (`playwright test`), `format:check`, `lint` with `--max-warnings 0` (enable once F13 is done).
- Add `.nvmrc` (Node LTS) and `packageManager` field.
- Playwright `webServer`: `pnpm build && pnpm start` when `CI` is set; reporter `[['list'], ['html', { open: 'never' }]]`.

## Done when
- `pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm test:e2e` all pass from a clean checkout.
