**Target:** dsem Level 3 · **Skill:** dsem-security (references/fastapi.md)

## What's wrong now
- `app/utils.py:360-377` uses one round of salted SHA-256; `:462-483` compares with non-constant-time `==`.
- `UserDB.hashed_password` is `String(96)` (`users/models.py:69`); recovery codes stored in plaintext (`users/models.py:71`).
- No minimum password length (`users/schemas.py:57,109`).

## What needs to change
- Use `pwdlib[argon2]` `PasswordHash.recommended()`; keep a legacy SHA-256 verifier and rehash on successful login (atomic save).
- Widen the column via Alembic.
- Hash recovery codes (Argon2 or HMAC) and compare in constant time.
- Add `min_length` ≥ 12 on password fields.

## Done when
- Tests cover: new Argon2 hash, legacy-hash login that rehashes, reset with hashed recovery code, short password rejected.
