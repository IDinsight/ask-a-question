**Target:** dsem Level 3 · **Skill:** dsem-api-setup (observability.md)

## What's wrong now
- No request ID, no access log with duration (grep: 0 hits for `request_id`/`X-Request-ID`).
- Background tasks (`question_answer/routers.py:239` `_chat`, docmuncher `process_pdf_file`) lose request context.

## What needs to change
- Middleware generates/accepts a UUID, stores it in a contextvar, sets `X-Request-ID`, logs method, path, status, `duration_ms`, `request_id`.
- Propagate the ID into background tasks; S1's catch-all handler logs with it.

## Done when
- Test asserts `X-Request-ID` header.
- Log lines for one request (incl. its background task) share the ID.
