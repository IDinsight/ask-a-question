**Target:** dsem Level 3 · **Skill:** dsem-api-skill

## What's wrong now
- All logic in `contents/routers.py` (1287 lines): quota (`:1127`), CSV checks (`:957-1125`), tag creation, direct query (`:1157`).
- `contents/models.py:132-338` persistence functions commit (7×) and call embeddings (`save_content_to_db`).
- Bulk upload commits per tag and per row (`:779-822`) — partial failure leaves partial data.

## What needs to change
- Add `contents/service.py` (create, edit, archive, validate, delete, bulk upload) and `contents/persistence.py`; embedding call moves to the service.
- Bulk upload in one transaction (tags + contents), rolled back on any failure.
- `ExceedsContentQuotaError` → `QuotaExceededError`.

## Done when
- Mid-file bulk-upload failure leaves zero new rows (test).
- Service tests cover quota, invalid tags, related content, embedding failure → `ExternalServiceError`.
- Router has no `select` or commit calls.
