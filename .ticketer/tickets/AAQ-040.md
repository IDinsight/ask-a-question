**Target:** dsem Level 3 · **Skill:** dsem-nextjs, dsem-security (references/nextjs.md)

## What's wrong now
- dsem-nextjs L3 assumes a Next server layer (`lib/api/server.ts` + `server-only`, cookie session, auth-checked Server Actions). admin_app is a client-only SPA: every page is `"use client"`, the browser calls FastAPI directly with a localStorage bearer token (`src/utils/api.ts`, `src/utils/auth.tsx:82-85`). No written decision exists.

## What needs to change
- Write an ADR (`docs/` or `admin_app/docs/`) choosing (a) BFF: httpOnly session cookie set by Next route handlers, `server-only` API module, middleware protection; or (b) documented SPA deviation with compensating controls (CSP, short TTL, all authZ in FastAPI).
- Record which skill rules are waived and why; confirm or replace F2/F3.

## Done when
- ADR merged with decision and consequences; F2/F3 updated accordingly.
