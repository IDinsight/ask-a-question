**Target:** dsem Level 3 · **Skill:** dsem-ci-cd §4 (Permissions, Level 3+)

## What's wrong now
- Repo default `default_workflow_permissions: write`, `can_approve_pull_request_reviews: true`.
- No `permissions:` block in `tests.yaml`, `linting.yaml`, `alembic-migrations.yaml`, `test_speech_api.yaml`; `set-env` jobs in all five deploy workflows inherit write; `docs.yaml:7-8` grants `contents: write` workflow-wide.

## What needs to change
- Top-level `permissions: contents: read` in every workflow; `id-token: write` only on GCP deploy jobs; move `contents: write` to the docs job.
- Set repo default to read; disallow Actions approving PRs.

## Done when
- Every workflow has a `permissions:` block; repo API shows `read` and `false`.
