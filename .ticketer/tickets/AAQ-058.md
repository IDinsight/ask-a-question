## What's wrong now
- This branch deletes `admin_app/package-lock.json` and adds `pnpm-lock.yaml`, but `admin_app/Dockerfile` still does `COPY package.json package-lock.json` + `npm ci` (`:7-8`), `npm run build` (`:17`) and copies `package-lock.json` again (`:29`). Base image `node:19-alpine` is EOL (same in `Dockerfile.dev`).
- `deploy_gcp_admin_app.yaml` runs on any push to main touching `admin_app/**`, so merging breaks the staging deploy.

## What needs to change
- Node LTS alpine base pinned to match `admin_app/.nvmrc`; `corepack enable`; copy `pnpm-lock.yaml`; `pnpm install --frozen-lockfile`; `pnpm build`; drop `package-lock.json` from the runner stage. Same for `Dockerfile.dev`.

## Done when
- `docker build admin_app` succeeds locally and in CI; image serves on port 3000.
