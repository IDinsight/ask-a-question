## Current state
core_backend is at **Level 2**. Business logic lives in routers, persistence functions in `models.py` own commits and call external services, there are no global exception handlers, no request IDs/structured logs, and transaction ownership is implicit. This epic introduces router → service → persistence layering per feature, data constraints/indexes, test isolation and L3 observability.
