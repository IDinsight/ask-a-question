**Target:** dsem Level 3 · **Skill:** dsem-nextjs

## What's wrong now
- 40 hand-written `Authorization: Bearer` headers; token threaded through every API function signature.
- Untyped `response.data` returns (e.g. `src/app/content/api.ts:53-71`); 32 `any` usages incl. `handleApiError(customError: any…)` (`src/utils/api.ts:20`).
- Duplicated error mapping (`src/app/workspace-management/api.ts:19-60` vs `src/utils/api.ts:20-37`). API modules live inside `app/`.

## What needs to change
- `src/lib/api/client.ts`: browser-safe axios instance, request interceptor for auth (or cookie credentials after F2), single `toApiError()` mapper.
- Move feature modules to `src/lib/api/{content,dashboard,urgency-rules,workspace,integrations}.ts` with typed request/response interfaces mirroring FastAPI schemas; drop `token` params.

## Done when
- No `Authorization:` literal outside `lib/api/client.ts`.
- Every exported API function has an explicit return type; `grep -rnE ': any|as any' src/lib` = 0; `tsc` passes.
