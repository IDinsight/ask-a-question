# PostgreSQL Reference

PostgreSQL 18 is the current stable release (released Sept 2025). Supported versions: 18, 17, 16, 15, 14 — each with 5-year support, no separate LTS designation. Read alongside `references/database/database.md`.

---

## Level 1 — naming only

Create the databases with correct names. No connection configuration required.

```bash
createdb {project_name}_dev
createdb {project_name}_test
```

Document the names in `.env.example` as placeholders with no values.

## Level 2 — connectivity and migrations

**Docker Compose** for local development:

```yaml
services:
  db:
    image: postgres:18
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: {project_name}_dev
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 5s
      timeout: 5s
      retries: 5

  db-test:
    image: postgres:18
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: {project_name}_test
    ports:
      - "5433:5432"   # different host port
    # no volume — ephemeral

volumes:
  postgres_data:
```

**Environment variables** — add to `.env.example`:

```
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/{project_name}_dev
TEST_DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5433/{project_name}_test
DB_CONNECT_RETRIES=5
DB_CONNECT_RETRY_INTERVAL_SECONDS=2
```

Use the `psycopg` (v3) driver. The URL prefix is `postgresql+psycopg://`.

**Connection with startup retry** (see stack reference for the full implementation):

```python
# utils/database.py — key pattern
engine = create_engine(url, pool_pre_ping=True)

for attempt in range(1, retries + 1):
    try:
        with engine.connect() as conn:
            conn.execute(text("SELECT 1"))
        break
    except Exception:
        time.sleep(interval * attempt)
```

**Alembic setup:**

```bash
uv add alembic
uv run alembic init migrations
```

Configure `migrations/env.py` to read `DATABASE_URL` from settings and point `target_metadata` at `SQLModel.metadata`. Create an empty initial migration to verify the toolchain before writing any models.

**Destructive migration gate:** if the generated file contains `drop_table`, `drop_column`, or `drop_index`, do not run it automatically. Tell the user the command and require manual execution after a backup.

## Level 3 — constraints, indexes, and test isolation

**Schema constraints.** All NOT NULL, unique, and foreign key constraints must be defined at the database level in migration files — not only in application code.

**Indexes.** Add an index for every column used in a WHERE, JOIN, or ORDER BY in application queries. Review autogenerated migrations for missing indexes before applying.

**Test database isolation** — transaction rollback per test:

```python
# tests/conftest.py
@pytest.fixture(scope="session", autouse=True)
def run_migrations():
    from alembic.config import Config
    from alembic import command
    cfg = Config("alembic.ini")
    cfg.set_main_option("sqlalchemy.url", settings.test_database_url)
    command.upgrade(cfg, "head")

@pytest.fixture(name="session")
def session_fixture():
    with Session(test_engine) as session:
        session.begin()
        yield session
        session.rollback()
```

Never substitute SQLite for PostgreSQL in tests — schema dialects differ.

## Level 4 — production pool and observability

**Full connection configuration:**

```
DB_POOL_SIZE=10
DB_MAX_OVERFLOW=20
DB_POOL_RECYCLE=1800
DB_POOL_TIMEOUT=30
DB_SLOW_QUERY_MS=500
```

Add all to `.env.example`.

```python
engine = create_engine(
    url,
    pool_size=settings.db_pool_size,
    max_overflow=settings.db_max_overflow,
    pool_recycle=settings.db_pool_recycle,
    pool_timeout=settings.db_pool_timeout,
    pool_pre_ping=True,
)
```

**Slow query logging via SQLAlchemy events:**

```python
@event.listens_for(engine, "before_cursor_execute")
def _before(conn, cursor, statement, parameters, context, executemany):
    conn.info.setdefault("query_start_time", []).append(time.monotonic())

@event.listens_for(engine, "after_cursor_execute")
def _after(conn, cursor, statement, parameters, context, executemany):
    elapsed_ms = (time.monotonic() - conn.info["query_start_time"].pop()) * 1000
    if elapsed_ms > settings.db_slow_query_ms:
        logger.warning("Slow query (%.1fms): %s", elapsed_ms, statement[:200])
```

**Health check** — must execute a real query and return 503 on failure:

```python
@app.get("/health")
def health():
    try:
        with Session(engine) as s:
            s.exec(text("SELECT 1"))
        db_status = "ok"
    except Exception:
        db_status = "unreachable"
    ok = db_status == "ok"
    return JSONResponse(
        status_code=200 if ok else 503,
        content={"status": "ok" if ok else "degraded", "checks": {"database": db_status}},
    )
```

## Level 5 — schema isolation and hardening

**Application schema** — use a dedicated schema instead of `public`:

```sql
-- run once as superuser during provisioning
CREATE SCHEMA IF NOT EXISTS app;
GRANT ALL ON SCHEMA app TO {app_user};
REVOKE ALL ON SCHEMA public FROM {app_user};
```

Set `search_path` in the connection URL: `?options=-csearch_path=app`.

**Additional hardening:**

- `ssl=require` — append `?sslmode=require` to the connection URL
- `ssl_min_protocol_version = 'TLSv1.2'` — set in `postgresql.conf`; rejects older TLS handshakes
- `password_encryption = scram-sha-256` — PostgreSQL default since v14; never use MD5 (being removed)
- `idle_in_transaction_session_timeout` — set in `postgresql.conf` or via `ALTER ROLE` to kill hung transactions
- `pg_stat_statements` — enable for production query analysis; identifies slow and frequently-run queries
- `authentication_timeout = 30s` — reduces exposure window for slow or hung auth attempts
- Database user has only `SELECT`, `INSERT`, `UPDATE`, `DELETE` on app tables — no `CREATE`, `DROP`, or superuser
- Automated daily backups verified restorable
